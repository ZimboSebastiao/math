##  Como Clonar e Rodar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/ZimboSebastiao/math.git
cd math
```

### 2. Compile um dos programas

Escolha um dos arquivos `.c` e compile com o GCC.  
Por exemplo:

```bash
gcc nome_do_arquivo.c -o nome_do_programa
```

### 3. Execute o programa

```bash
./nome_do_programa
```
